THE ALPHA FACTORY

A machine that keeps building trading edges, testing each honestly, sailing the ones that pass, and scrapping the ones that rot. We don't bet on a strategy (they decay) — we bet on the process. HOW AN ENGINE FIRES — one trade, signal to exit

Every engine speaks the SAME language: it defines ONE rule (select), then the framework runs the identical maths — realised outcome minus the Tide (market drift) = alpha (skill). Here is a single worked trade through each of the three Roster engines.

🌊 Wave Rider slot · momentum · 3-day hold · LIVE-shadow
① SIGNAL
10:00 ET — TSLA is +4.2% vs yesterday, holding above its opening VWAP
② SELECT
it's a WILD stock making an UP move ≥3% → qualifies
③ ENTER
buy 1 of 5 slots: 8 sh @ $250 (~$2k), stop $230 (−8%)
④ HOLD
3 business days — the crowd keeps arriving
⑤ EXIT
day-3 close: sell @ $265 (+6.0%)
✓ ALPHA
+6.0% − Tide +1.2% = +4.8% skill
↩️ Contrarian sleeve · reversal · 5-day hold · market-neutral
① SIGNAL
rank all ~290 names by their last 3 days of return
② SELECT
LONG the worst loser (SYM −13%), SHORT the best winner (XYZ +16%)
③ ENTER
a balanced basket — small equal weights on both legs
④ HOLD
5 business days — the rubber band snaps back
⑤ EXIT
loser bounces +3%, winner fades −1%
✓ ALPHA
both legs beat the Tide; market move cancels (pays bull or bear)
🌙 Clockwork overnight book · consistency · 1 night · LIVE-shadow
① SIGNAL
15:50 ET — rank WILD names by 30-day up-night consistency
② SELECT
CC gapped up 73% of the last 30 nights → top of the list
③ ENTER
buy at the close: 83 sh @ $12.00 (~$1k, 1 of 10)
④ HOLD
overnight — the money made while you sleep
⑤ EXIT
next open: sell @ $12.18 (+1.5%)
✓ ALPHA
+1.5% − overnight Tide +0.4% = +1.1% skill

Illustrative numbers. The key point: three different edges, one identical honesty test — outcome − Tide = alpha — so no engine can flatter itself.

CLOCKWORK — LIVE PAPER (overnight book · Night Shift v2) {% if f.ovn.mode=='LIVE' %}LIVE ORDERS{% else %}SHADOW · no orders{% endif %}

Directional overnight book on live-shadow (not a market-neutral Roster engine — it fails the gate's cost check once you charge a full round-trip every night, which an overnight book always pays). Near the close, rank WILD stocks by how consistently they've gapped up (last 30 nights), buy the top ~10, hold overnight, sell at the open. It carries overnight beta, so its RAW return is positive at realistic costs; the forward shadow test measures real net-of-fills. Shadow = records intended trades, places no orders.

CONTRARIAN — LIVE PAPER (mean-reversion sleeve) {% if f.contra.mode=='LIVE' %}LIVE ORDERS{% else %}SHADOW · no orders{% endif %}

Buys the biggest 3-day fallers, 5-day hold, 15% stop, earnings blocked, with a SPLIT_MAX_DROP filter that rejects un-split-adjusted price artifacts. Run concentrated (2 slots × ~$5,000) rather than as the ~100-position breadth book the Proving Ground scored — that was a deliberate call to dodge IBKR's $1 minimum commission, which is 1% per side at $100/position. It is long-only (the short leg carried only +0.116% of the +0.355% alpha for all the borrow risk), so it is no longer market-neutral: judge it on alpha vs the tide, not raw P&L. Two known biases inflate any Contrarian backtest — unadjusted splits and a universe screened partly on past performance — so only the forward run is clean. This panel was missing entirely until Sep 11 2026.
